What the set ratings mean

  • Simple. Easy: you could do 4 or more extra reps. Medium: about 3. Hard: 1–2. Max effort: not one more clean rep.
  • RIR (reps in reserve): how many more good reps you could have done. 0 = none, 4+ = four or more.
  • RPE (rate of perceived exertion): 10 = nothing left, 9 = one rep left, 8 = two, and so on. 8.5 means “two, maybe one”.

How the rest timer options work

  • iPhone Clock timer. A web page can't ring while the phone is locked, but the Clock app can. After each set, tap Start iPhone timer in the rest bar: Shortcuts starts a Clock timer for the planned rest and brings you back to LiftLog.
  • Keep the screen on. While the workout screen is open, the phone won't auto-lock, so the built-in timer stays visible. Works on HTTPS in current Safari and Chrome; other browsers simply ignore it.
  • Beep. A short sound when the rest is over, only while LiftLog is on screen.

Make the iPhone shortcut (once, ~2 minutes)

  1. Open the Shortcuts app (Skróty) and tap + in the top right corner.
  2. Tap the shortcut's name at the top, choose Rename and type exactly the name from the settings above: {{ form.instance.ios_shortcut_name|default:"LiftLog Rest" }}.
  3. Tap Add Action, search for Start Timer (it belongs to the Clock app; in Polish look for „minutnik” under Zegar) and tap it.
  4. The action reads “Start timer for 30 minutes”. Tap 30, choose Select Variable and then Shortcut Input (Dane wejściowe skrótu).
  5. Tap minutes and change it to seconds. LiftLog sends the rest length in seconds, e.g. 90.
  6. Tap Done.
  7. Back here, switch on iPhone Clock timer via Shortcuts and save.
  8. In a workout, log a set and tap Start iPhone timer in the rest bar. The first time, iOS asks whether LiftLog may open Shortcuts: tap Open. If Shortcuts asks for permission to run the action, tap Always Allow.
Not working?
  • “Shortcut not found”: the name here and in Shortcuts must match exactly, including spaces and capital letters.
  • Timer has the wrong length: check that the unit is seconds. If the variable can't be chosen, add the action Get Numbers from Input before Start Timer and use its result as the duration.
  • You end up in Safari instead of the home-screen app: that's how iOS handles the return link; your sets are saved either way.
