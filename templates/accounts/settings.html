{% translate "What the set ratings mean" %}

  • {% blocktranslate trimmed %}Simple. Easy: you could do 4 or more extra reps. Medium: about 3. Hard: 1–2. Max effort: not one more clean rep.{% endblocktranslate %}
  • {% blocktranslate trimmed %}RIR (reps in reserve): how many more good reps you could have done. 0 = none, 4+ = four or more.{% endblocktranslate %}
  • {% blocktranslate trimmed %}RPE (rate of perceived exertion): 10 = nothing left, 9 = one rep left, 8 = two, and so on. 8.5 means “two, maybe one”.{% endblocktranslate %}

{% translate "How the rest timer options work" %}

  • {% blocktranslate trimmed %}iPhone Clock timer. A web page can't ring while the phone is locked, but the Clock app can. After each set, tap Start iPhone timer in the rest bar: Shortcuts starts a Clock timer for the planned rest and brings you back to LiftLog.{% endblocktranslate %}
  • {% blocktranslate trimmed %}Keep the screen on. While the workout screen is open, the phone won't auto-lock, so the built-in timer stays visible. Works on HTTPS in current Safari and Chrome; other browsers simply ignore it.{% endblocktranslate %}
  • {% blocktranslate trimmed %}Beep. A short sound when the rest is over, only while LiftLog is on screen.{% endblocktranslate %}

{% translate "Make the iPhone shortcut (once, ~2 minutes)" %}

  1. {% blocktranslate trimmed %}Open the Shortcuts app and tap + in the top right corner.{% endblocktranslate %}
  2. {% blocktranslate trimmed with name=form.instance.ios_shortcut_name|default:"LiftLog Rest" %}Tap the shortcut's name at the top, choose Rename and type exactly the name from the settings above: {{ name }}.{% endblocktranslate %}
  3. {% blocktranslate trimmed %}Tap Add Action, search for Start Timer (it belongs to the Clock app) and tap it.{% endblocktranslate %}
  4. {% blocktranslate trimmed %}The action reads “Start timer for 30 minutes”. Tap 30, choose Select Variable and then Shortcut Input.{% endblocktranslate %}
  5. {% blocktranslate trimmed %}Tap minutes and change it to seconds. LiftLog sends the rest length in seconds, e.g. 90.{% endblocktranslate %}
  6. {% blocktranslate trimmed %}Tap Done.{% endblocktranslate %}
  7. {% blocktranslate trimmed %}Back here, switch on iPhone Clock timer via Shortcuts and save.{% endblocktranslate %}
  8. {% blocktranslate trimmed %}In a workout, log a set and tap Start iPhone timer in the rest bar. The first time, iOS asks whether LiftLog may open Shortcuts: tap Open. If Shortcuts asks for permission to run the action, tap Always Allow.{% endblocktranslate %}

  • {% blocktranslate trimmed %}You end up in Safari instead of the home-screen app: that's how iOS handles the return link; your sets are saved either way.{% endblocktranslate %}
